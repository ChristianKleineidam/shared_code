# Shared code and reproducible experiments

A collection of independently reusable code, experiments, benchmarks, and their supporting evidence.

## Projects

- [Dart SIMD vs C: STFT windowing benchmark](dart-eardea-simd-comparison/) — reproducible Dart AOT / C kernel comparisons, Windows measurements, and an experimental unaligned SIMD-load prototype motivated by audio preprocessing.

Each project maintains its own implementation and reproducibility instructions. This repository is designed to host unrelated projects alongside one another.
